# Northstar Workspace

A responsive React and TypeScript admin workspace for reviewing team activity, managing users, and viewing account settings.

## Getting started

```bash
npm install
npm run dev
```

Sign in with any valid email address and password to open the demo workspace.

## Available commands

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build locally

## Features

- Protected dashboard, users, user profile, and settings routes
- Shared user state across the dashboard and user management pages
- Add a user and navigate directly to their profile
- Search users and navigate between pages using the workspace navigation
- Responsive layout with reduced-motion support

User and sign-in data are demo-only and stored in memory or browser storage; this project is not connected to a backend.
